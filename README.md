# I Wanna: 反向安全屋

一个轻量的 Canvas 平台跳跃小游戏，风格接近 I Wanna 系列的“记忆型坑点”关卡。

## 打开方式

直接用浏览器打开 `index.html` 即可运行，不需要安装依赖。

## 操作

- `A / D` 或方向键左右移动
- `W / Space / ↑` 跳跃，可二段跳
- `R` 在当前存档点重开
- `Enter` 在通关后重新开始

## 当前坑点

- 安全牌下方会弹出尖刺
- 奖励物会主动飞向玩家
- 天花板会掉落
- 部分平台会移动或碎裂
- 假存档点会逃跑并露出尖刺
- 某一区域会短暂左右反向
- 钥匙会后撤
- 终点第一次会假动作
